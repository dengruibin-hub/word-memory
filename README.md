# 我的单词本

一个无需注册、直接在浏览器使用的个人背单词小工具。

## 功能

- 自由添加英文单词、中文释义和例句
- 卡片式背词：先看单词，再查看释义
- 浏览器英文发音
- 「认识了 / 不认识」复习机制，自动安排下次复习日期
- 优先复习掌握度较低的单词
- 搜索、删除和管理词库
- JSON 导入 / 导出，方便备份
- 深色模式
- 手机、平板、电脑自适应
- 数据默认保存在当前浏览器的 localStorage 中

## 使用

直接打开 `index.html` 即可使用。无需安装 Node.js，也没有构建步骤。

## 发布到 GitHub Pages

在 GitHub 仓库中打开 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)`，保存后等待 GitHub Pages 完成发布。

> 注意：因为词库保存在浏览器本地存储中，换设备或清理浏览器数据后不会自动同步。建议定期使用「导出词库」备份。
